# Contact Connect Hub

Contact Connect Hub is a web-based contact management application designed to help users organize, manage, and maintain their professional and personal contacts in one place.

## 🌐 Live Demo

https://contactconnecthub-1.onrender.com

## ✨ Features

- Add and manage contacts
- Save contact details such as name, phone, email, company, job, address, and notes
- Search and organize contacts
- Favorites
- Contact categories
- Reminders and follow-ups
- Relationship management
- QR-based contact sharing
- vCard support
- AI Assistant
- AI-powered contact insights
- Duplicate and suspicious-number detection
- Responsive and user-friendly interface

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- SQLite

### Other
- QR Code generation
- REST APIs
- AI API integration
